گام ۱: مشخصات حساب و توکن Cloudflare

بازکردن داشبورد ↗

در داشبورد Cloudflare به بخش Workers & Pages بروید؛ شناسه حساب در URL داشبورد مشخص است.

ساخت API Token ↗

برای استفاده از دفترچه، حساب را پس از واردکردن مشخصات ذخیره کنید. Token در مرورگر با AES-GCM رمزگذاری می‌شود و رمز اصلی ذخیره نمی‌شود.

دفترچه امن حساب‌ها (حداکثر ۱۰ حساب)

برای نگهداری رمزگذاری‌شده حساب‌ها، ابتدا دفترچه را ایجاد یا باز کنید.
دسترسی‌های لازم:
• برای ساخت Worker جدید یا Clean Rebuild: نقش Workers Admin در سطح حساب.
• برای اتصال D1: دسترسی D1 Edit.
• برای ساخت KV: دسترسی Workers KV Storage Edit.
• برای اتصال دامنه: دسترسی مدیریت Worker و فعال بودن Zone دامنه در همین حساب.

گام ۲: سورس و مشخصات Worker

برای به‌روزرسانی، نام Worker موجود را وارد کنید. نام باید با حروف کوچک و عدد شروع شود.

فقط لینک خام GitHub یا Gist پذیرفته می‌شود. فایل باید یک اسکریپت Worker آماده استقرار باشد.

دامنه باید از قبل در همین حساب Cloudflare فعال باشد. رکورد DNS و گواهی توسط Cloudflare مدیریت می‌شود.

مبهم‌سازی سورس کد (Obfuscator)همان روش رشته‌ای XOR/Base64 مورد استفاده Jasaz؛ ممکن است با بعضی سورس‌ها ناسازگار باشد و رمزنگاری واقعی نیست.
حذف و بازسازی مجدد Worker (Clean Rebuild)در صورت وجود Worker با همین نام، ابتدا حذف و سپس از صفر ایجاد می‌شود. در صورت شکست آپلود، نسخه قبلی خودکار برنمی‌گردد؛ منابع Durable Object متعلق به Worker نیز ممکن است حذف شوند.
⚠️ مبهم‌سازی را فقط وقتی فعال کنید که سورس را تست کرده‌اید. برای سورس‌های از پیش مبهم‌شده مانند بعضی نسخه‌های Nahan، مبهم‌سازی مجدد را فعال نکنید.

گام ۳: منابع ذخیره‌سازی اختیاری (D1 و KV)

ساخت یا اتصال پایگاه‌داده D1اگر دیتابیسی با همین نام وجود داشته باشد، به همان متصل می‌شود؛ در غیر این صورت ایجاد می‌شود.
ساخت یا اتصال KV Namespaceفضای KV موجود با همان عنوان پیدا می‌شود؛ اگر وجود نداشته باشد ساخته خواهد شد.

نکته: این مرحله فقط منابع را ایجاد/پیدا و Binding آن‌ها را روی Worker تنظیم می‌کند؛ ساخت جدول‌ها و داده‌های اولیه دیتابیس بر عهده سورس Worker است.

پایش سلامت و بازسازی خودکار

پس از استقرار موفق و ذخیره حساب در دفترچه، پایش قابل فعال‌سازی است.
هنوز پایشی انجام نشده است.

هشدار: Rebuild خودکار ابتدا Worker قبلی را حذف می‌کند. از آن برای Workerهای دارای Durable Object بدون پشتیبان استفاده نکنید. پایش مرورگری با بسته‌شدن صفحه یا قفل دفترچه متوقف می‌شود.

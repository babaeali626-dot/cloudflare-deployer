به‌روزرسانی Zeus Cloud Deployer v3.3-Cron — بازسازی با اولین خطا

چه چیزی تغییر کرده است؟
- آستانه بازسازی خودکار دقیقاً ۱ خطای واقعی Health Check است.
- مقدار قبلی failureThreshold=3 که در D1 ذخیره شده بود نادیده گرفته می‌شود و زمان بازسازی قدیمی نیز در اولین اجرای نسخه جدید یک‌بار پاک می‌شود؛ لازم نیست تنظیمات حساب‌ها را دستی پاک کنید.
- هنگام اولین خطای واقعی، Clean Rebuild با recreateWorker=true اجرا می‌شود: Worker قبلی از Cloudflare حذف و سپس سورس ذخیره‌شده دوباره روی همان نام نصب می‌شود.
- این رفتار هم در پایش پس‌زمینه Cron و هم در پایش مرورگر اعمال شده است.
- خطاهای API، توکن نامعتبر، مجوز ناکافی یا خطای رمزگشایی نامشخص هستند و به‌تنهایی باعث حذف Worker نمی‌شوند.

محدودیت ایمنی:
- برای جلوگیری از حلقه حذف/نصب، بین تلاش‌های بازسازی حداقل یک ساعت فاصله است.
- پس از یک Health Check سالم، محدودیت یک‌ساعته پاک می‌شود؛ بنابراین خرابی بعدی با اولین خطای واقعی دوباره بازسازی را شروع می‌کند.
- Auto Rebuild باید روشن باشد و حساب باید مجوز Clean Rebuild داشته باشد.

نحوه به‌روزرسانی:
۱) ZIP کامل را استخراج کنید و محتویات پوشه cloudflare-deployer را در همان مسیر پروژه GitHub جایگزین کنید؛ یا فایل‌های ZIP افزونه را در مسیرهای متناظر جایگزین کنید.
۲) تغییرات را Commit/Push کنید تا Cloudflare Pages به‌روزرسانی شود.
۳) از ترمینال، داخل پوشه cloudflare-deployer، Cron Worker را دوباره Deploy کنید:

npx wrangler deploy --config cron-worker/wrangler.toml

نیازی به ساخت D1 جدید، تغییر شناسه D1 یا تنظیم مجدد VAULT_ENCRYPTION_KEY نیست. Secret فعلی Cron حفظ می‌شود.

توجه:
- در ZIP افزونه، فایل cron-worker/wrangler.toml قرار داده نشده تا شناسه D1‌ای که قبلاً تنظیم کرده‌اید ناخواسته بازنویسی نشود.
- ZIP کامل شامل D1 قبلی شماست: zeus-deployer-db و شناسه 2fb661ce-00a8-4ae8-b165-76f73256f697.
- Clean Rebuild عمداً Worker موجود را حذف می‌کند. Secretها و تنظیمات اختصاصی‌ای که فقط روی Worker ذخیره شده‌اند و در تنظیمات پنل بازسازی نمی‌شوند، ممکن است از بین بروند؛ پیش از استفاده از آن‌ها نسخه پشتیبان داشته باشید.
- بازسازی همان scriptUrl ذخیره‌شده را دوباره دانلود می‌کند. اگر خود سورس GitHub خراب باشد، نصب مجدد همان سورس ممکن است همان خطا را تکرار کند؛ در این حالت ابتدا باید سورس اصلاح شود.
